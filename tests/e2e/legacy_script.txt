# Legacy line-based script: `ja2 -run` translates .txt scripts to Lua, so
# scripts written for the old -uitest driver keep working. Pixel coordinates
# here are for 1280x720, the smallest resolution the game runs at (ctest passes -res 1280x720).
#
# Commands: move X Y | click X Y | rclick X Y | key NAME | type TEXT | wait MS
#           waitpixel X Y #RRGGBB [tol] [timeoutMs] | waitstable X Y [timeoutMs]
#           assertpixel X Y #RRGGBB [tol] | screenshot PATH

# The driver starts at the main menu; the bottom left corner, left of the
# footer line, is black.
waitstable 40 700 5000
assertpixel 40 700 #000000 8
move 10 10
wait 500
key o          # "Preferences" hotkey
wait 1000
key ESC
wait 1000
screenshot legacy.png
