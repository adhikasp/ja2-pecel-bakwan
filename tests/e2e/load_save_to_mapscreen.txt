# E2E: boot -> Continue Saved Game -> load a save -> verify the strategic world map.
#
# Fixtures: the saves in ~/.ja2/SavedGames/ (Day 1, Arulco, 0 mercs). These are
# older-version saves, so loading triggers an "update save?" confirmation.
# Coordinates captured at -res 1280x720; recalibrate if resolution/UI art changes.
#
# Every step uses a waitpixel anchor instead of a fixed sleep so the script is
# robust against the (variable, ~10s) intro splash and save-load times.

# 1. Wait for the main menu: gold "START NEW GAME" text at its center.
waitpixel 640 407 #a48d41 20 25000

# 2. Click "CONTINUE SAVED GAME" -> opens the LOAD GAME screen.
click 640 445
waitpixel 620 143 #a4854a 30 10000   # gold "LOAD GAME" title

# 3. Select the first save slot.
click 400 183
wait 600

# 4. Click "Load Game".
click 534 571

# 5. Confirm the "older version" dialog (white "Attention" text) -> YES.
waitpixel 640 335 #ffffff 16 8000
click 601 402

# 6. Wait for the strategic world map to appear. (779,164) is the yellow highlight
#    box around the player's current sector (A9/Omerta) on the map grid - bright
#    and present only on the strategy MAP_SCREEN.
waitpixel 779 164 #ffff00 16 40000

# 7. Let the map screen's fade-in finish before asserting (the whole screen ramps
#    up in brightness over ~2s after it first appears).
wait 3000

# 8. Assert the strategic world map is loaded by checking two static brass-frame
#    highlights of the map/roster panels (these do not pulse, unlike the sector box).
assertpixel 375 232 #eee6cd 20
assertpixel 577 280 #eee6cd 20

# 8. Capture proof for visual inspection.
screenshot /tmp/ja2_e2e_mapscreen.bmp
