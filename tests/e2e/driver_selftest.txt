# Driver self-test: verify assertpixel passes and fails correctly
# This test validates the UITestDriver's own pixel-assertion logic
# without depending on specific game-screen content.
#
# The driver's readPixel returns false (and assertpixel prints a FAIL)
# for out-of-bounds coordinates, which is deterministic.
#
# Assertions:
#   1. Pixel (-1,-1) is out of bounds → expected FAIL
#   2. Pixel (10000,10000) is out of bounds → expected FAIL
#
# These are guaranteed to fail in a predictable way so we can verify
# the driver's error handling without needing calibrated coordinates.

assertpixel -1 -1 #000000 8
assertpixel 10000 10000 #ffffff 8

wait 1000
