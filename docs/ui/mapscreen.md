## 1. How it was audited

- `tests/e2e/manual/phase4_audit.lua`: a real campaign (new game, Barry + Ivan hired, before and after landing, the
  landing sector cleared with the new test aid `ja2.debug("clearenemies")`), dumping screenshot + clickable elements +
  visible text of ~40 states at 1920x1080 (filters, selection, assignment/squad/train/attribute/repair menus, contract,
  sleep, sort, multi-select, plotting and confirming a route, move box, town info, sub-levels, merc and sector inventory,
  messages, time compression, help, settings, pre-battle).
- Code read: the files listed above. Keyboard map is complete from `HandleModNone/Shift/Ctrl/Alt`.

## 7. Edge cases

- [x] No mercs: map works, "hire mercs" hint (S19), plotting/assign disabled.
- [ ] 20 mercs + vehicles: table scrolls; grouping keeps squads together.
- [ ] Vehicles (no reassignment, condition/fuel), EPCs (need escort to move, `pMapErrorString[6/7]`), robot (repair target), dead (remove), POW (morale "??"), in transit (ETA, no reassignment), between sectors.
- [ ] Combat / hostiles in sector: time compression locked, no movement orders, sector inventory manual only.
- [ ] Underground sectors not visited are hidden.
- [ ] Long strings (German/Russian) in menus and the team table: ellipsis + tooltip.
- [ ] 1280x720 (same layout scaled), 21:9 (docks grow), 32:9, 4K, UI scale 150/200 %.
